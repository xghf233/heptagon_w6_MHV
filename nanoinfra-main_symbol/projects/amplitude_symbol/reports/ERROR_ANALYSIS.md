# 错误集分析：word_bidi 500K vs 150K（全量 val）

> 分析日期: 2026-08-17 | 数据: 两个最终 checkpoint 的全量 val 逐样本预测（26,388 样本）
> 工具: [analyze_errors.py](../analyze_errors.py)（新文件） | 关联报告: [WORD_BIDI_150K_REPORT.md](WORD_BIDI_150K_REPORT.md) 遗留问题 C

## 一、方法

- 用 `eval_checkpoint.py --save-predictions` 对 500K 和 150K 最终 checkpoint 各生成一份
  全量 val 预测（`outputs/amplitude_symbol/big_eval/*/predictions_val.json`，样本顺序一致）。
- 错误定义：`pred != true`（两个模型全程 0 invalid，不存在解码失败类错误）。
- 两份预测的 exact 与各自 evaluation JSON 逐位一致（99.003% / 98.935%），无重复生成误差。

## 二、总体数字

| 指标 | 500K | 150K |
|------|------|------|
| 错误数 / 26,388 | 263 (1.00%) | 281 (1.06%) |
| Invalid | 0 | 0 |
| Sign-only 错误（模相同、符号错） | 20 (7.6%) | **55 (19.6%)** |
| Magnitude 错误（符号对、模错） | 220 (83.7%) | 190 (67.6%) |
| 符号与模都错 | 23 (8.7%) | 36 (12.8%) |

错误以 **magnitude 为主**（两个模型都 ~70–84%）；两模型的差异几乎全部集中在
**sign**：150K 比 500K 多 35 个符号错误。这与大评估的 sign 精度差（99.84% vs 99.66%）吻合。

## 三、错误重合度

| 指标 | 值 |
|------|-----|
| 共同错误 | 227 / 263（500K 错误的 86%） |
| Jaccard | 0.716 |
| 共同错误中输出相同错误答案 | 77 (34%) |
| 500K 对、150K 错 | 54 样本 |
| 150K 对、500K 错 | 36 样本 |

**大部分错误是共享的**（86%）——两个模型在基本相同的样本上失败；但共同错误中只有
1/3 给出相同的错误答案，说明失败的是"样本难"而非"同一个坏规则"。
单边分歧上 500K 净胜 18 个样本（54 vs 36），是 500K 略优的全部来源。

## 四、错误在哪：轨道视角

500K 的 263 个错误只落在 **47 个 D3 轨道**上（150K: 54 个）；39 个轨道双方都错。
前几大错误轨道的全部 6 个成员都错，且预测**高度轨道内自洽**：

| 轨道 (true) | 500K 整轨预测 | 150K 整轨预测 |
|-------------|--------------|--------------|
| aaaaaaeeee (9216) | -4352×5, -1024×1 | **-19680×6** |
| aaeaeaaeee (-2912) | **-2880×6** | **-2880×6**（同一错误答案） |
| aaeceecddd (-1344) | -1216×6 | -1376×6 |
| aaaeeaffff (-6400) | **-5568×6** | **-5568×6**（同一错误答案） |
| aaeceeafff (-192) | -64×6 | -64×2, +64×4（150K 轨道一致性被打破） |
| abfaaaeeee (864) | 752×6 | 576×6 |
| aaabbddbff (-96) | **正确** | +96×6（150K 整轨符号翻转） |

含义：**错误不是随机噪声，而是模型对少数轨道学到了"错但一致"的规则**。这也解释了
为什么轨道一致性指标（99.5%）远高于 exact——模型在自己错的地方也自洽。
两模型共享失败轨道，但多数轨道上各自学到的错误规则不同（39 个共享轨道中只有 9 个
逐成员输出完全一致）。

## 五、错误在哪：系数规模视角（关键发现）

错误率按 |true| 的十进制位数：

| 位数 | 样本数 | 500K 错误率 | 150K 错误率 |
|------|--------|------------|------------|
| 1 | 498 | 0.00% | 0.20% |
| 2 | 15,756 | 0.30% | 0.29% |
| 3 | 8,832 | 1.46% | 1.71% |
| **4** | **1,242** | **7.00%** | **6.68%** |
| 5 | 60 | 0.00% | 0.00% |

- **4 位系数是错误热点**：只占样本 4.7%，却贡献了 1/3 的错误（500K 的 87/263），
  错误率是 3 位的 ~5 倍、2 位的 ~23 倍。4 位即 base-1000 双 block（`+9|216`）——
  多 block 生成是主要失败模式（87 个错误中 75 个输出了另一个 4 位数，即两个 block 都生成了但值错）。
- 4 位错误只集中在 **16 个轨道**——不是普遍的多 block 困难，而是特定轨道的坏规则。
- 5 位样本（仅 60 个、10 个轨道、7 个特殊值如 ±10240、±11520、69120）全部正确：
  它们是稀有但高度结构化的特殊系数，模型完全掌握了。
- 典型错误是**量级接近的近失**：-2912→-2880、-1344→-1216/-1376、-192→-64、
  -6400→-5568——高位 block 常对、低位 block 错（base-1000 逐 block 解码的典型失败）。

## 六、150K 与 500K 的差异定位

- 差异几乎全部是 **sign**：150K 的 55 个符号错误落在 15 个轨道上，多为整轨 6 成员
  一起翻号（如 aaabbddbff: -96→+96×6）。
- 150K 比 500K 多错的 15 个轨道里，500K 只有 8 个轨道是 150K 不会错的——即 150K
  多出来的失败轨道大部分不是 500K 独有的强项，只是换了一批轨道错。
- 同一轨道两模型学到的错误规则可以完全不同（aaaaaaeeee: -4352 vs -19680），
  说明这些轨道的正确答案需要模型"猜"出训练中没直接见过的规则组合。

## 七、结论与下一步

1. **错误的本质**：~50 个轨道上的系统性坏规则 + 4 位系数多 block 生成。总错误率
   已到 1%，单纯加训练量收益有限（150K 与 500K 错误集 86% 重合）。
2. **可尝试的改进**（按性价比）：
   - **轨道对称性后处理**：错误高度轨道内一致，用轨道内投票/对称约束修正可直接
     消除大部分整轨错误（成本最低，纯推理侧）。
   - **多 block 系数增采样**：4 位系数仅占 4.7%，可对 train 中双 block 样本加权/复制，
     或加入系数 block 拆分的辅助任务。
   - **错误轨道与 train 的结构距离分析**：orbit-grouped split 保证错误轨道不出现在
     train，可进一步查"错误词与最近 train 词"的编辑距离/字母多重集差异，判断是
     结构泛化失败还是特定字母组合的盲区。
   - **多 seed**：同 seed 已有 ±1–2pp 波动，错误轨道集合（47 vs 54）也随 run 变化，
     多 seed 可分辨"固定难轨道"与"随 run 漂移的轨道"。
3. 500K 相对 150K 的净优势 = 18 个分歧样本 + 35 个 sign 错误，量级与"多训 350K 步"
   的投入不匹配——预算结论不变。
